## 4. Search Intent Architecture & Analysis

The portfolio is structured across the three core search intents defined in the CSET489 syllabus:

```
                                  PORTFOLIO SEARCH INTENT
                                             │
        ┌────────────────────────────────────┼────────────────────────────────────┐
        │                                    │                                    │
  [ INFORMATIONAL (50%) ]            [ COMMERCIAL (33%) ]                [ TRANSACTIONAL (17%) ]
  • Top of Funnel (TOFU)             • Middle of Funnel (MOFU)            • Bottom of Funnel (BOFU)
  • "best free ai tools for..."      • "cursor vs github copilot"         • "free alternatives to..."
  • "ai tools for literature review" • "chatgpt vs claude for coding"     • "free ai tools no credit card"
  • Purpose: Topical Authority       • Purpose: Decision Matrices         • Purpose: Immediate Action
```

1. **Informational Intent (6 Keywords / 50%):**  
   Targets searchers seeking educational methodology, study stacks, and guidance on navigating academic integrity rules. These queries build high topical authority and rank for long-tail informational snippets.
2. **Commercial Investigation Intent (4 Keywords / 33%):**  
   Targets searchers evaluating alternatives or comparing two competing solutions (e.g., *Cursor vs Copilot*, *ChatGPT vs Claude*). These searchers require structured comparison tables, pros/cons breakdowns, and objective trade-offs.
3. **Transactional Intent (2 Keywords / 17%):**  
   High-intent queries where the user is looking for an immediate zero-cost replacement (e.g., *free alternatives to chatgpt*). Our platform solves this friction immediately with verified free replacement cards.

## 5. Keyword Selection Rationale & Cannibalization Prevention

### Selection Criteria:
1. **Low Competition / High Feasibility (Target KD < 20):**  
   As a new domain with zero paid backlinks, targeting generic head keywords like `ai tools` (KD > 85) would result in zero organic visibility. We specifically target compound modifiers (`free`, `for students`, `for academic research`, `vs`) where top-ranking domains exhibit weak, outdated, or ad-cluttered content.
2. **Strict Topic-to-URL Exclusivity (Anti-Cannibalization Rule):**  
   Every keyword is mapped to exactly **ONE** canonical page on the website. Category hubs target plural categorical queries (`ai tools for academic research`), pillar guides target specific intent phrases (`best free ai tools for students`), and comparison routes target specific pair names.
